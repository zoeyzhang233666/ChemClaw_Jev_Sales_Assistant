# Jev 化工 B2B 销售副驾 · 第一阶段

本分支基于原 Android Jev 聊天助手，保留微信/QQ/X/飞书的聊天采集、OCR、悬浮窗和**人工发送**方式，将原来的关系/情绪判断改为化工 B2B 客户沟通判断。

## Jev 在业务链中的位置

聊天采集 → 本机联系人/笔记上下文 → **Jev 同一次调用判断 7 项** → 生成模型读取 Jev 判断及聊天事实起草 3 条候选 → **Jev 第二次调用对候选排序** → 销售人员核对、填入并手动发送。

原实现判断和回复生成并行；本分支改为先判断再生成，确保生成模型确实收到 Jev 的业务判断。原项目的 API Key 设置、Jev 判断接口及生成接口继续复用。

## Jev 判断题（兼容原项目 JSON 字段）

| 兼容字段 | 新含义 |
| --- | --- |
| `true_intent` | 产品咨询/询价/议价/索样/索取资料/交付或订单/售后/其他 |
| `danger_level` | 缺失信息和商业承诺风险；**不是化学品危险性分级** |
| `she_needs` | 最重要的缺失条件：产品身份/规格/数量/目的地/交期/有效报价/库存/文件/无 |
| `should_reply_now` | 是否具备已验证事实，足以具体回答 |
| `best_action` | 下一步销售动作（核实产品/数量/交货/价格/库存/资料/样品/人工复核/订单） |
| `tension_resolved` | 正式报价条件是否完备 |
| `literal_question` | 是否需要有资质人员进行技术、安全或合规复核 |

旧字段名是 **wire-format 兼容层**，不是新业务术语；下一阶段再迁移到独立的 ChemicalAnalysis 数据类，以免第一阶段破坏现有 UI 和客户端。Jev 结果是辅助决策，不能替代库存、价格、资质、技术与运输审核。

## 快速测试用例

| 客户消息 | 主要预期 |
| --- | --- |
| 有工业级异丙醇吗？ | product_inquiry，询问级别/规格或检查产品数据 |
| 异丙醇 99.9%，5 吨送苏州，多少钱？ | request_quote，check_price；没有有效价格时不能直接报数 |
| 别家报 6550，你能做到吗？ | negotiate_price；核实同规格/交货条件及公司授权价格 |
| 发一下这个批次的 COA | request_documents，send_documents；不得伪造文件 |
| 有什么能替代这款进口溶剂？用于涂料 | product_inquiry，technical/human_review；不能保证替代效果 |
| 之前那单到哪儿了？ | delivery_order，follow_up_order；不得编造发货状态 |

## 开发/验收

```bash
./gradlew assembleDebug
```

需要 JDK 17 + Android SDK platform/build-tools 35。仓库代码已修改，但在没有 Android SDK 和真实 API Key 的环境下不能声称 APK 或 Jev 在线调用已验收。
